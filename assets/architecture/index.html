System 03

CI execution route

Configured steps execute in order. A step marked as a gate stops the route when it fails; fail-fast can make every failure terminal.

  1. self-checkVerify required toolsConfigured gate
  2. fmt --checkVerify Rust formattingContinue by default
  3. lintRun ClippyWorkspace or selected crates
  4. compile-testsBuild test binariesCatch compile failures early
  5. testRun nextestBehavioral evidence
  6. check-depsFind unused dependenciescargo machete
  7. check-protocol-driftCompare contract hashesLockfile evidence
