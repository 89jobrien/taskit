A smaller operating surface

One command vocabulary from first check to release.

Taskit wraps the tools Rust teams already trust, then adds workspace-aware selection, durable governance, and a consistent result model.

A

Affected work, not blanket work

Compare committed changes with origin/main, match configured crate directories, then apply one pass of directory-keyed propagation rules.

P

Protocols stay deliberate

Hash selected contract files into taskit-protocol.lock so reviewed boundaries cannot drift silently.

H

Health has evidence

Capture a replaceable test, Clippy, safety, and coverage baseline, then inspect CI and flow telemetry trends in a read-only terminal dashboard.

F

Flow is an executable policy

Promote work through configurable development, staging, release, and main branches; full automation runs CI on the release branch.

Command map

Grouped by operator intent.

Every family has focused help. Structured formats are available where pipeline results are emitted, and supported operations expose a global --dry-run flag.

taskit dev
Build, bootstrap, install hooks, set up tools, clean, and update.
taskit check
Run formatting, Clippy, quick feedback, CI, dependency checks, and hooks.
taskit test
Drive nextest, coverage, properties, fuzz targets, benchmarks, reports, and snapshots.
taskit health
Capture baselines, inspect thresholds, and compare telemetry with recent history.
taskit protocol
Guard contract hashes, construction sites, TODOs, freshness, and dependency policy.
taskit release
Bump versions, publish packages in order, and create a GitHub release.
taskit flow
Inspect, synchronize, promote, guard, or automate the configured branch route.
taskit self
Install Taskit, run its cached self-test, and verify its required tooling.

Top-level surfaces: taskit init, taskit dashboard, and taskit changelog.

Configuration is optional

Start with Cargo metadata. Add policy when you need it.

Without a config file, Taskit discovers the workspace. A small taskit.toml makes dependency propagation and tracked contracts explicit.

taskit.tomlworkspace policy
[workspace]
crates = [
  { dir = "crates/core", pkg = "acme-core" },
  { dir = "crates/cli", pkg = "acme-cli" },
]

[[workspace.propagation]]
source = "crates/core"
dependents = ["crates/cli"]

[[protocol.surfaces]]
name = "public-api"
path = "crates/core/src/lib.rs"
Discover

Useful without setup

Walk upward to the workspace root and derive package information from Cargo.

Declare

Propagation is reviewable

Name the downstream crate directory entries that must run when a shared source directory changes.

Lock

Contracts become evidence

Update the protocol lock intentionally, then review the source and hash together.

Branch orchestration

Promotion follows a named route.

develop→staging→release auto: CI→main→develop

taskit flow promote advances one merge stage without running CI. taskit flow auto runs the complete route from a clean development branch and gates the release stage with the default pipeline.
